This is a [Quarto](https://quarto.org/) project.

All markdown content is in the single `<ROOT>/index.md` file.

Markdown guidelines:
* use labeled environments, eg theorem blocks
* use section labels
* use bibtex citations with `<ROOT>/references.bib`
* mermaid diagrams can be used with appropriate syntax
* these are notes but use proper capitalization, and in paragraphs use complete sentences
* don't use bold text
* italics can be used sparingly for emphasis
* don't use horizontal rules
* sections should be used consistently to collect a unit of conceptually-related text
  and make the text easier to navigate, not just to
  break up long sequences of paragraphs. Too many small deeply nested sections
  disrupt readability.
* when citing, always use square brackets: [@foo], not @foo, not [-@foo]
